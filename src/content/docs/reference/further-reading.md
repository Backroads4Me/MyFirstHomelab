The best next resource depends on what you are building. Start with official documentation for exact commands, then use community discussions for ideas and troubleshooting context.

## Communities

- [r/homelab](https://www.reddit.com/r/homelab/): hardware, networking, rack layouts, and project inspiration from homelab builders.
- [r/selfhosted](https://www.reddit.com/r/selfhosted/): discussion of software you can operate on your own systems.
- [Proxmox Community Forum](https://forum.proxmox.com/): searchable installation, storage, networking, and virtualization discussions.
- [Self-Hosted Community](https://selfhosted.show/): a podcast and community focused on practical self-hosting experiences.

Community posts can become outdated. Check dates, read follow-up comments, and confirm commands against the project's current documentation.

## Official Documentation

- [Proxmox VE Administration Guide](https://pve.proxmox.com/pve-docs/pve-admin-guide.html): the authoritative reference for installing, updating, networking, storage, backups, VMs, and containers.
- [Docker documentation](https://docs.docker.com/): installation, Compose, storage, networking, and security guidance maintained by Docker.
- [Dockhand User Manual](https://dockhand.pro/manual/): stacks, environments, updates, data paths, and Docker management.
- [Heimdall documentation](https://docs.linuxserver.io/images/docker-heimdall/): current image, ports, settings, and Compose example.
- [Beszel documentation](https://beszel.dev/guide/getting-started): hub and agent installation, pairing, and monitoring.
- [Dozzle documentation](https://dozzle.dev/guide/getting-started): current Docker log viewer installation and configuration.
- [Debian Reference](https://www.debian.org/doc/manuals/debian-reference/): concise reference material for packages, the shell, networking, storage, and system services.

## Learning Resources

- [Linux Journey](https://linuxjourney.com/): short lessons on the command line, permissions, processes, networking, and other Linux fundamentals.
- [Docker Get Started](https://docs.docker.com/get-started/): guided exercises that introduce images, containers, and multi-container applications.
- [Proxmox VE video tutorials](https://www.proxmox.com/en/services/training-courses/videos/proxmox-virtual-environment): official demonstrations of Proxmox features and workflows.
- [Awesome Selfhosted](https://awesome-selfhosted.net/): a categorized catalog for discovering software; evaluate maintenance, documentation, and backup requirements before deploying anything.

Choose one small project at a time, document what you changed, and make a backup before each major experiment.
